# SQL Data Analytics Project

This project focuses on exploratory data analysis (EDA) using SQL Server and sales datasets.

The goal of the project is to analyze customer, product, and sales data using SQL queries to generate business insights and practice analytical thinking.

---

## 📊 Project Objectives

The project includes analysis such as:

- Database exploration
- Dimensions and measures exploration
- Date range analysis
- Magnitude analysis
- Ranking analysis
- Customer and product reporting

---

## 🛠️ Tools & Technologies

- SQL Server Express
- SQL Server Management Studio (SSMS)
- SQL
- Git & GitHub

---

## ⚙️ SQL Concepts Used

- SELECT, WHERE, ORDER BY
- GROUP BY & Aggregations
- JOINS
- CTEs
- Window Functions
- Subqueries
- CASE Statements
- Ranking Functions
